# 子主題 01：平台架構與契約

> 本地來源：`README.md`、`docs/{usage,testing,api,project_structure,system_inventory,decision_nodes,legacy_inventory}.md`、`physim/{__init__,service,contracts,cli}.py`、`physim/core/`、`physim/app/`、`physim/render/`、`tests/`
> 蒸餾日期：2026-11-12

## 1. 一句話定位

physim 是一個「三層分離」的物理模擬平台：`physim/core` 只含純資料與契約（不 import UI/renderer），`physim/domains` 提供數值模型，`physim/app` 與 `physim/render` 負責 Streamlit/panel/CLI/匯出。所有模型透過 registry 註冊，scene 與參數以 dataclass/frozen dataclass 傳遞，快取集中在 numerics 層。

## 2. 分層架構與責任邊界

| 層 | 目錄 | 可 import | 禁止 |
|----|------|-----------|------|
| 核心契約 | `physim/core` | `ParamSpec`, `ParamSet`, `Preset`, `BaseModel`, `ModelMeta`, `Scene2D/3D`, registry, cache | UI / renderer / Streamlit / panel / pyvista |
| 數值層 | `physim/domains/<domain>/numerics.py` | numpy/scipy、純函式、lru_cache | UI、scene |
| 模型適配層 | `physim/domains/<domain>/models.py` | core + numerics → `BaseModel` 子類，`register(...)` | 直接 import Streamlit |
| 渲染層 | `physim/render` | Scene → matplotlib/pyvista 輸出 | 業務邏輯 |
| 應用層 | `physim/app`、`physim/cli.py`、`physim/service.py` | core + render | 直接呼叫 numerics（應經 model） |

來源：`README.md`「架構」「設計決策」、`docs/project_structure.md`、`SKILL.md`「分層架構」。

## 3. 核心契約

- **ParamSpec** (`physim/core/params.py`)：單一參數的 schema（name/label/default/low/high/step/unit）。
- **ParamSet**：參數集合，model.frame(params) 以此取值。
- **Preset**：命名參數組合（例：`Preset("標準", {"t":1.0,"a":1.0}, "預設")`）。
- **BaseModel**：抽象基底，需實作 `meta`、`params`、`presets`、`frame(params,index)`、`summary(params)`、`frame_count(params)`。
- **ModelMeta**：id/title/domain/description/kind/fps/n_frames/tags。
- **Scene2D/Scene3D**：渲染中間表示（lines/surfaces/hlines/title/xlabel/ylabel/xlim/ylim）。
- **registry**：`register(ModelInstance)`；CLI/UI 透過 id 取得模型。
- **cache**：lru_cache 集中在 numerics 層（例：`band_path` maxsize=32、`tight_binding_1d` maxsize=256）。

## 4. 對外介面

| 介面 | 入口 | 說明 |
|------|------|------|
| Streamlit | `physim/app`（streamlit_app） | 互動式儀表板，preset/深連結/匯出 |
| panel | `physim/app`（panel_app） | 獨立 panel 入口 |
| CLI | `physim/cli.py` | 命令列執行/匯出 |
| Python service | `physim/service.py`、`contracts.py` | 程式化 API（`docs/api.md`） |
| 深連結 | URL query params | 選擇模型/參數 |
| 匯出 | render → png/mp4 | 圖/動畫 |

來源：`docs/usage.md`（安裝/Streamlit/panel/CLI/Python service/深連結）、`docs/api.md`。

## 5. 快取與效能

- 快取：`functools.lru_cache` 集中於 numerics；昂貴的 k 網格（band_path/band_grid/berry_grid）maxsize=32；tight_binding maxsize=256。
- 環境變數/快取鍵：見 `README.md`「快取與環境變數」段（未深讀，標 `> ⚠️ 未驗證`）。
- 效能門檻：`docs/testing.md` 測試矩陣與效能門檻；嚴格 3D 驗收。
- 快取釋放：`clear_numeric_cache()`（bands）等顯式清理函式。

## 7. 設計決策與已知限制

- 不修改 `physim/core` 以 import Streamlit/panel/pyvista（分層鐵律）。
- 舊檔保留原位；新程式使用 adapter/numerics，不直接 import 舊檔。
- `physimOld` 只讀不 import。
- 未遷移項目（`docs/system_inventory.md`）：舊 Streamlit 互動編輯器、額外物理主題、非物理頁面。
- 文件缺口（`docs/decision_nodes.md` A 節）：README/usage/testing 需補。
