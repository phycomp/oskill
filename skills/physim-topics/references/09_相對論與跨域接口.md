## 1. 一句話定位

相對論域提供狹義/廣義相對論模型；本 repo 的跨域需求來源是 `曼量子傳輸線LLM範例.md`（兩家客戶的 10 條需求），它們對應到外部 qcable 技能群。全 repo 共 22 個 domain，此檔附總表作為索引收尾。

## 2. 相對論域（`physim/domains/relativity/`）

| 模型 id | 標題 | 數值函式 | 說明 |
|---------|------|---------|------|
| `relativity.time_dilation` | 時間膨脹 | `time_dilation(v_max,n)` | γ(v) 與速度關係（動畫標記當前速度） |
| `relativity.orbit` | 相對論軌道（近似） | `relativistic_orbit(M,r0,t_end,n)` | 牛頓二體軌道（Schwarzschild 近似可後續） |

資料結構：`TimeDilationData`（v, gamma）、`RelativisticOrbitData`（t, x, y）。數值：`scipy.integrate.solve_ivp`（rtol 1e-9）。

## 4. 外部技能接口地圖

`qcable-index` 技能索引的子技能群（`~/.opencode/skills/qcable-index/`）：

| 子技能 | 職責 |
|--------|------|
| `generic-qcable` | 通用量子傳輸線設計/計算/優化/重構 |
| `quantum-cryogenic-cable` | 低溫線纜設計與重構整合 |
| `heatload-simulation` | 熱負載模擬（傅立葉定律非線性積分 + 衰減器自發熱） |
| `heatload-measurement` | 低溫熱負載量測 |
| `heatload-sop` | 量測 SOP |
| `heatload-units` | μW/W/mK/dB 單位換算 |
| `polar` | Speedstack/Si9000 Polar 模板採樣 |
| `mantaro` | Mantaro 風格阻抗計算器 |
| `crosstalk-calc` | NEXT/FEXT 串擾 |
| `component-integration` | 衰減器/LPF/IR filter 整合 |
| `connector` | RF 連接器選型與測試 SOP |
| `electrical-spec` | 電性規格定義 |
| `electrical-test-sop` | VNA/TDR/低溫電性測試 SOP |
| `material-db` | 材質屬性查詢與驗收 |
| `three-view` | 三視圖繪製 |
| `measurement-unit-link` | 量測單位鏈結（KPI-5） |

`topological-insulator` 技能（`~/.opencode/skills/topological-insulator/`）：TI 材料/拓撲超導/量子計算，與本 repo 的 BHZ/Berry 實作互補。

本子主題只做路由，不重抄技能內容。
