## 4. 跨主題結論

1. **physim 是第四代最終形態**：三層分離（core 不 import UI/renderer）、registry、preset、深連結、lru_cache、測試矩陣。前三代保留原位。
2. **所有物理主題皆依 core 契約註冊**：ParamSpec/ParamSet/BaseModel/Scene2D/3D/registry/cache，模型 id 形如 `domain.model`。
3. **微波級聯是工程價值最高的一段**：CST → ABCD/T → 特徵分解外插 → S，兩條路線（CST Schematic / scikit-rf）。
4. **能帶/拓撲鏈最完整**：BHZ → Berry/Chern → Wannier → 混合變分 → ML 加速 → 最小作用量原理，且與 `topological-insulator` 技能互補（本 repo 做計算，TI 技能做材料選型）。
5. **量子傳輸線需求來自外部客戶**：`曼量子傳輸線LLM範例.md` 的 10 條需求對應到 `qcable-index` 技能群。
6. **未遷移項目**：舊 Streamlit 互動編輯器、聲學、額外物理主題、非物理頁面（`docs/system_inventory.md`）。
