## 2. bands domain 實作

### 2.1 BHZ 兩能帶模型（`bands/bhz.py`）

Hamiltonian：
```
H(k) = t sin(kx) σx + t sin(ky) σy + [m + t(cos kx + cos ky)] σz
```
- `bhz_hamiltonian(kx,ky,m,t)` → 2×2 複數矩陣
- `bhz_d(...)` → 3D d-vector（用於能隙/拓撲相判斷）
- `bhz_bands(...)` → ±|d| 兩能帶
- `bhz_eigenvector(..., band=0|1)` → 本征向量（Berry 計算用）
- `bhz_gap(m,t)` → Γ 與 M 點最小直接能隙

拓撲相條件（來源註解）：`-2 < m/t < 0` 或 `0 < m/t < 2` 為拓撲相；能隙在 Γ 或 M 關閉。

### 2.2 k 路徑與網格（`bands/kpath.py`、`bands/numerics.py`）

- `square_kpath(n_per=90)`：Γ → X → M → Γ 高對稱點路徑，回傳 `(k, 累積距離, ticks, labels)`。
- `band_path(m,t,n_per)`（lru_cache 32）：路徑能帶，frozen `BandPathData`。
- `band_grid(m,t,nk)`（lru_cache 32）：2D k 網格能帶，frozen `BandGridData`。
- `berry_grid(m,t,nk,band)`（lru_cache 32）：Berry 曲率網格，frozen `BerryGridData`。
- `clear_numeric_cache()`：測試/長時間執行時釋放。

### 2.3 Berry 曲率與 Chern 數（`bands/berry.py`）

採 **Fukui–Hatsugai–Suzuki plaquette** 方法：
- `berry_curvature_grid(m,t,nk,band)`：對每格 `(kx,ky)` 取四角本征向量 `u, ux, uy, uxy`，計算 plaquette link `u†ux · ux†uxy · uxy†uy · uy†u`，取 `arg(link)/(dk²)`。
- 上能帶（band=1）曲率 = 下能帶的相反。
- `chern_number(omega)`：`sum(omega) * (2π/nk)² / (2π)`。
- `berry_curvature_at(kx,ky,...)`：單點曲率（測試/marker 用）。

### 2.4 BHZ 模型參數化（`bands/models.py`）

- `BandStructure2D`：2D 能帶結構視圖（Scene2D，含 Γ/X/M ticks）。
- `BandSurface3D`：3D 能帶曲面（Scene3D）。
- `BerryCurvature2D` / `BerryCurvature3D`：Berry 曲率視圖（含 Chern 數顯示）。

參數：`m`（Dirac 質量）、`t`（躍遷）、`nk`（網格解析度）、`band`（0/1）。

### 2.5 Wannier 緊束縛模型（`bands/wannier.py`）

- `WannierTB(hr, er, Rlist, nw)`：`H(k)=Σ_R h_R e^{ik·R}`、`O(k)=Σ_R e_R e^{ik·R}` 通用 tight-binding。
- `fake_graphene_photon(nw,t,eps)`：舊版示範模型（回歸測試用，非 UI 預設）。
- `Hk_Ok(k)`：回傳 Hermitian 化的 H(k), O(k)。
- `solve_k(k, nb)`：廣義本征值 `eigh(H,O)`，O 奇異時 fallback 到 `eigh(H)`。
- `eigenvectors(k, band)`：本征向量（O 度量歸一化）。
- `berry_curvature(k0, band, dk)`：以 O 度量的 plaquette 曲率。
- `parse_wannier90_dat(source)`：解析 Wannier90 的 `hr.dat`/`er.dat`，回傳 `(hr, er, Rlist, nw)`。

## 3. 混合變分法推導鏈

來源：`變分/維尼變分物理公式.md`、`變分/能帶Berry變分加速收斂.md`、`變分/作用量材料.md`。

完整鏈路（所有符號與 `WannierTB` 程式碼對應）：

1. **Maxwell 拉格朗日**：`ℒ = ½∫[ε(r)|E|² − μ₀⁻¹|B|²]`，`B=∇×E/(iω)`。
2. **週期展開**：`ε(r)=Σ_G ε_G e^{iG·r}`。
3. **Wannier 基底展開**（取代平面波）：
   - `w_n(r−R) = (1/N_k) Σ_k e^{-ik·R} u_{nk}(r)`
   - `u_{nk}(r) = Σ_R e^{ik·R} w_n(r−R)`
   - `E_k(r) = Σ_{n,R} c_n(k) e^{ik·R} w_n(r−R)`
4. **廣義本征值**：`Σ_m [H_{nm}(k) − ω² O_{nm}(k)] c_m(k)=0`，其中
   - `H_{nm}(k)=Σ_R e^{ik·R} H_{nmR}`
   - `O_{nm}(k)=Σ_R e^{ik·R} O_{nmR}`
   - 程式對應：`WannierTB.Hk_Ok(k)` 回傳這兩個矩陣。
5. **Wilson-loop Berry 曲率**：
   - `Ω_n(k) = (1/δ²) Im ln ∏_{μ=0}^{3} ⟨u_{k_μ}|u_{k_{μ+1}}⟩`
   - `C_n = (1/2π) ∫_BZ Ω_n(k) d²k`
6. **小擾動正定化**：`O_{nm}(k) ← O_{nm}(k) + 10⁻⁸ δ_{nm}`，避免 `O(k)` 奇異（詳見 §6）。

## 4. Berry 曲率與 Chern 數

- **Berry 連接**：`A_n(k)=⟨u_{n,k}| i∇_k |u_{n,k}⟩`
- **Berry 曲率**：`Ω_n(k)=∇_k×A_n · ẑ`（2D 純 z 分量）
- **離散微環**：plaquette 四邊形 `k → k+δ → k+δ+δ → k+δ → k`
- **Chern 數**：BZ 網格求和 `C_n = (1/2π) Σ Ω_n(k) δ²k`

程式對應：`bhz.py`/`berry.py` 的 `berry_curvature_at` 與 `berry_curvature`（Wannier 版）。

## 5. ML 加速變分收斂

來源：`變分/能帶Berry變分加速收斂.md`。

- **代理模型**：`f_θ(k)` 預測能帶能量 ω_pred（輸入 (kx,ky)，輸出 nw 個值）。
- **損失**：`ℒ(θ)= (1/N) Σ_i ‖f_θ(k_i)−ω_i‖²`
- **梯度**：`∇_θℒ = (2/N) Σ_i (f_θ(k_i)−ω_i) ∇_θ f_θ(k_i)`
- **主動學習採樣**：`k_new = arg max_k ‖∇_θ f_θ(k)‖`（最大梯度不確定度）
- **混合精度**：前向/loss 用 FP16，梯度累加用 FP32，速度 ≈3×
- **Wannier 優勢**：矩陣維度 5–20 vs 平面波 100–500，代理輸入從 500 值降到 10 值，訓練速度 ↑>10×。

程式對應：`WannierSurrogate`（nn.Module，`nn.Linear(2,hidden)→Tanh→…→nw`）。

## 6. 數值穩定性修正

來源：`變分/修正項.md`。

問題：`scipy.linalg.eigh(H, O)` 要求 O 正定，但 O(k) 在離散 k 點可能出現零/負本徵值 → 廣義本征值無解 → Wilson-loop/Berry 計算中斷。

三種修復方案：
1. **偵測奇異並跳過**：該小格只用 H（`eigh(H, subset_by_index=[b,b])`）。
2. **加微小常數（推薦）**：`O(k) += 1e-8 * I`；數值誤差 < 1e-6，不影響 Berry 曲率精度。
3. **用 `scipy.linalg.eig`**：算所有本徵值後丟掉負的，再排序取前 nb 個。

程式已實作方案 2 的 fallback：`WannierTB.solve_k` 在 `LinAlgError/ValueError` 時改用 `eigh(H)`。

## 7. 最少作用量原理（`變分/作用量材料.md`；`最少作用量.py` 為「量子相位干涉四大模型」Streamlit App）

> 註：`最少作用量.py` 實際是 Streamlit 互動展示 App，標題「量子相位干涉四大模型」，整合 AB 雙狹縫、一維隧道、瞬子(虛時)、Berry phase 自旋 四個模型（與 `physim/domains/quantum/` 對應），非「最少作用量」計算。檔名與內容不符，屬命名誤導（`> ⚠️ 未驗證` 是否有意為之）。

最小作用量原理為能帶計算提供統一理論框架：`𝒜 = ∫ L dt → δ𝒜 = 0`。

應用範例：
1. **光子晶體混合變分法**：`ℒ = ½[ε(r)E² − μ⁻¹(r)B²]`，週期展開 + 變分求解 → 光子能帶 ω_n(k)；相比平面波展開收斂更快。
2. **路徑積分與鞍點近似（量子體系）**：瞬子方法計算能帶寬度 `(Δu)_m = (ω/π√α) exp[-ℏ^{1/2} S_1(u_m)]`，给出隧穿效應的精確關係。
3. **場論變分法（關聯電子體系）**：自由能泛函 `ℱ = ℱ_0 + Σ_q [U/2|Δ_q|² − T Σ_{ω_n} Tr ln(G⁻¹)]`，自洽求解序參量 → 重整化「磁性能帶」`E_k^σ = ε_k + σ Δ_k`。

技術對比：

| 方法 | 計算精度 | 收斂速度 | 適用體系 |
|------|---------|---------|---------|
| 混合變分法 | 高 | 快 | 光子/聲子晶體 |
| 路徑積分瞬子法 | 極高（指數精度） | 中等 | 低維量子體系 |
| 傳統平面波法 | 依賴截斷 | 慢 | 弱關聯電子 |
| 密度泛函理論 | 中 | 快 | 弱–中等關聯 |

前沿方向：拓撲能帶理論（作用量與 Berry 曲率 `ℒ_Berry = k·Ω(k)`）、非厄米體系（復相空間延拓）、機器學習加速（神經網絡參數化試探波函數）。
